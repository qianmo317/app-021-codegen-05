# 教室座位轮换编排 · Classroom Seating Rotation

按周/月自动轮换学生座位：近视的靠前、个高的靠后、同桌组合不重复、每人都有机会坐中间 —— 一次排好一学期的座位表。

技术栈：**React 18 + TypeScript + Vite**，手写 CSS（不引入 UI 库），运行时依赖仅 `react` / `react-dom` / `lucide-react`（图标，本地打包）。

## 隐私底线（必读）

> **所有学生数据只保存在你自己的浏览器（IndexedDB）中，不上传任何服务器。**
> 本应用是纯前端应用：没有后端、没有账号系统、没有任何网络请求会把名单或座位表发送出去。
> 清除浏览器数据会删除名单，请谨慎操作；导出的文件请自行妥善保管。
> 仓库 `.gitignore` 已排除真实学生名单与导出文件（`classes/`、`exports/`、`*.xlsx`），**未成年人信息绝不入库**。

## 功能

1. **班级与座位图**：行列数、过道位置、门/窗方向、小组围坐（4 人一组）布局；自动标注前排/中排/后排/靠窗/靠门/靠过道。
2. **学生名单**：姓名、身高、视力状况（需前排/需中间）、特殊需求（听力/行动不便）、学习分层、备注；支持批量粘贴导入。
3. **硬性约束**：视力需求前 N 排、身高排序（高个靠后）、必须分开的学生对、固定座位 —— 生成与手工微调时都强制满足（违反数为 0）。
4. **轮换生成**（核心）：带种子的模拟退火 + 局部交换改善，生成一学期（如 20 周）座位表，附公平性报告（逐人统计：前/中/后排次数、同桌列表）。同参数 + 同种子结果完全一致（可复现）。
5. **手工微调**：拖拽交换任意两人，实时预览「交换后公平性变化」，违反硬约束的交换会被拒绝并可一键撤销；支持「重新生成第 N 周」「从第 N 周起重排」（已过周次不变）。
6. **同桌长期台账**：逐周累积同桌对（生成新一周或手工微调后自动重算），可查任意两人这学期同桌过几次、分别在第几周；一眼看出每个学生和谁坐得最多、有没有一整个月都跟同一个人坐。同桌次数上限可配（默认 2 次），超上限的对在列表中红色标出并建议「下次换座时分开」；教师还能给任意一对标记「以后不要再同桌」——标记后每周生成都按硬约束避开这一对，手工把他们拖成同桌也会被拒绝。
7. **导出与打印**：按周导出座位表 CSV、全班公平性统计 CSV、同桌台账 / 每人同桌汇总 / 指定两人同桌记录 CSV；每周座位表 A4 一页打印（含讲台方向指示）。

## 页面结构

```

/class/:id/setup     座位图与学生名单、约束配置（含同桌次数上限）
/class/:id/rotations 轮换结果（按周查看、单周重排、拖拽微调）
/class/:id/fairness  公平性报告（逐人统计）
/class/:id/deskmates 同桌台账（逐周记录、两人查询、超限标红、整月同桌、黑名单）
/class/:id/print     座位表打印（按周）
```

## 算法说明（给家长看的依据）

- **位置分** `positionScore(seat) = rowWeight + middleWeight`：前后排权重 0~2、中间度权重 0~1，**分数越低位置越好**。
- 引擎在硬约束（视力/听力/行动不便/固定座位/必须分开）全部满足的前提下，最小化「每人累计位置分与平均分之差的平方和」，让每个人坐好位置的机会均等；同时均衡每人「前 N 排」的次数（极差 ≤ 3）。
- **同桌** = 行列模式下同排左右相邻（隔过道不算）；轮换期内目标「任意两人同桌 ≤ 上限次（默认 2，可在配置中调整）」，超限会在公平性报告与同桌台账中列出并建议下次分开；教师可把任意一对加入「以后不要再同桌」黑名单，引擎按硬约束（HARD 级）每周避开。
- **同桌台账**：不另存副本，每次查看都由全部周次座位表（`assignments`）经 `buildDeskmateLedger()` 重算，因此新生成一周或手工交换后记录立即一致；「整月同桌」按「学期第 1 周周一」（可在台账页设置，默认建班当周周一）把周次映射到自然月，连续同桌周次（周一~周日）完整覆盖某个自然月即标出。

## 边界（刻意不做）

不做排课表与教师课务、不做学生成绩录入与查询、不做考勤点名、不做家长端应用与消息推送 —— 核心只做**座位编排 + 公平性统计 + 打印**。
